# 🐠 Aquario Python — Mapeamento e Filtragem de Dados

## 📌 Objetivo do Projeto

O gerente do aquário forneceu uma base de dados contendo registros de diversos animais (nome, espécie, número do tanque atual e tipo). O objetivo do sistema é:

1. Carregar a base de dados em formato `.json`.
2. Identificar e filtrar apenas os animais do tipo **peixe** (`"fish"`).
3. Mapear a lista contendo apenas os nomes desses peixes.
4. Realocar todos os peixes identificados para um novo tanque específico.
